# Soul Sunny Studio

A Notion-style place to collect ideas, sites and apps. One file: `index.html`, nothing to install.

## Use it
Open `index.html` in a browser (or host it with GitHub Pages).

- **Pages** grouped as Idea / Site / App / Note, each with an icon, cover, status and link.
- **Blocks**: text, headings, lists, to-dos, quotes, callouts, code, images, files, links, dividers.
- Add blocks with the **Add:** buttons, the **+** next to a line, or by typing **/**.
- Paste or drag & drop images and files onto a page. Drag **⋮⋮** to reorder.

## Where data is saved
In your browser (IndexedDB) on that device only. Use **Export** in the sidebar for a backup file and **Import** to restore it or move it to another device.
